Sillonette - BETA VERSION (English summary of LISEZMOI.txt, which stays the reference)
=====================================================================================

Sillonette shows in OBS the track playing on YouTube Music, WITHOUT any server:

  YouTube Music tab -> extension -> OBS on this PC (OBS WebSocket server, 127.0.0.1)
  -> JavaScript event -> overlay (local file) in an OBS Browser source.

Nothing leaves the PC, except the album covers, which the overlay loads from Google
(as YouTube Music does).

You need: Windows 10/11, OBS Studio 28 or newer (WebSocket and Browser are included),
Chrome, Edge or Opera.

WARNING: beta version. Tried successfully by the author on Windows with a real OBS, and tested
automatically on Linux. NOT YET TESTED over long periods (several hours of streaming).
Keep a fallback for your streams.

Download: only from https://github.com/fushoo22/sillonette/releases
MIT licence: Sillonette is provided "as is", without warranty.
Sillonette is an independent, free project, not affiliated with YouTube, Google or the OBS Project.

Zip content: extension-chrome\ (the extension), overlay\ (the overlay for OBS:
sillonette-overlay.html), LISEZMOI.txt (full guide, in French), README-EN.txt (this file).


1. Unzip
--------
Right-click the zip -> "Extract All..." -> pick a folder you will KEEP, for example C:\Sillonette\
(Not Downloads: if the folder is deleted, the extension and the overlay are gone.)


2. Turn on the OBS WebSocket server
-----------------------------------
a. Open OBS. Menu Tools -> WebSocket Server Settings.
b. Tick "Enable WebSocket server". Keep port 4455.
c. Keep "Enable Authentication" ticked and KEEP the password generated by OBS. Do not use a short
   one: OBS does not limit the number of attempts.
d. Click "Show Connect Info", then the "Copy" button to the right of "Server Password".
   Do not copy the dots shown: they only hide the password.
   (Not during a stream: this window shows the password, QR code included.)
e. Click OK. If Windows asks to allow OBS through the firewall, you may refuse (Cancel):
   Sillonette only needs this PC itself (not yet checked with Sillonette).

THIS PASSWORD GIVES FULL CONTROL OF OBS: scenes, start/stop streaming and recording, READ or
CHANGE THE STREAM KEY... OBS has no "limited" password. Never show it on screen, never give it to
anyone. Sillonette only connects to OBS on this PC, only sends the current track, and never sends
the password itself (only a proof computed from it). The password is stored NOT ENCRYPTED, by OBS
in its settings and by the extension in the browser profile. The OBS WebSocket server also listens
on your local network, without encryption: only the password protects it.


3. Install the extension
------------------------
a. Open the extensions page: chrome://extensions (Chrome), edge://extensions (Edge),
   opera://extensions (Opera).
b. Turn on "Developer mode".
c. Click "Load unpacked" and pick the extension-chrome folder (the one with manifest.json).
d. Pin "Sillonette" (puzzle icon -> pin).


4. Connect the extension to OBS
-------------------------------
a. Click the Sillonette icon (a small disc). The window follows your browser's language;
   the FR / EN buttons at the top switch it.
b. OBS WebSocket port: 4455 (unless you changed it in OBS).
c. OBS WebSocket password: paste the password copied in step 2d.
   "Keep it after the browser closes": ticked, it works by itself after a restart.
d. Click "Save and connect". The dot turns green: "Connected to OBS."
   - "OBS not found": OBS is closed or its WebSocket server is off (step 2).
   - "Password refused by OBS": copy it again with the OBS "Copy" button (step 2d).
   - "You pasted the dots that hide the password": use the OBS "Copy" button. Nothing was changed.
   - ORANGE dot "OBS asks for NO password": it works, but any device on your network can control
     OBS. In OBS, tick "Enable Authentication".
e. Pick the skin and the layout. The window shows the recommended size of the source.


5. Add the overlay to OBS
-------------------------
a. In OBS, create a NEW source: Sources -> + -> "Browser" -> name it "Sillonette".
b. Tick "Local file", click "Browse" and pick overlay\sillonette-overlay.html
c. Width 800, Height 200 (or the size recommended by the extension), then OK.


6. Try it
---------
Open https://music.youtube.com (reload the tab if it was open) and play a song: it shows up in OBS
within about a second. One YouTube Music tab at a time: a second tab gets the code E10.
Closing the tab empties the overlay at once; if the browser is closed, it hides after 20 seconds.


7. Customize the overlay
------------------------
a. Click the Sillonette icon, then "Customize...". A page opens in a tab.
   (Or: extensions page -> Sillonette -> Details -> "Extension options".)
b. Set colours, background opacity, corners, cover shape, shadow, title font, size, what is shown,
   animations, behaviour when paused and with no music, alignment, overlay language. The preview
   shows "Demo (made-up tracks)" or "Live (your music)": the track Sillonette sends to OBS right now,
   in the page only, even without OBS (the cover comes from Google, as in OBS). Every setting is saved at once and reaches OBS within a few seconds.
c. If you change the size or the layout, copy the "Recommended size" into the source's Width/Height.
d. "Reset the skin's settings" brings back the skin's own settings.

Only a few seconds at each new track: "Behaviour" -> "When to show the card" -> "A few seconds at
   each new track", then the duration (10 seconds by default, 3 to 60). The card shows when the
   track changes, then hides until the next track. It does NOT come back when you resume after a
   pause. An error code (E10) always stays visible.

Going further: OBS "Custom CSS". Right-click the Sillonette source -> Properties -> "Custom CSS".
   KEEP the line already there (body { ... }) and add your rules below it. Examples:
     .sillonette .title { text-transform: uppercase; }
     .sillonette .title, .sillonette .line2 { text-shadow: 0 0 3px #000, 0 0 3px #000; }
   If a rule does nothing with a skin, add !important before the semicolon. These rules stay in
   OBS: Sillonette does not see them. To go back, delete your lines.


Update
------
Nothing updates by itself. Download the new zip, extract it INTO THE SAME FOLDER replacing the files
(BOTH folders: extension-chrome and overlay; an old overlay ignores the new settings), then on the
extensions page click "Update" (or the round arrow on the Sillonette card). In OBS, if the old
display stays: right-click the source -> Properties -> "Refresh cache of current page".
The password and the settings stay saved in the browser.


Uninstall
---------
Sillonette window -> "Forget the password", then extensions page -> Sillonette -> Remove.
Delete the Sillonette source in OBS. If you think the password leaked: in OBS, Tools ->
WebSocket Server Settings -> "Generate Password", then OK.
