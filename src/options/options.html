Aller plus loin : le « CSS personnalisé » d'OBS

Pour un réglage absent de cette page (titre en majuscules, contour du texte…), ouvre les propriétés de la source Navigateur dans OBS et écris des règles dans « CSS personnalisé », sous la ligne déjà présente. Exemple :

.sillonette .title { text-transform: uppercase; }

Le mode d'emploi (LISEZMOI.txt) donne d'autres exemples. Ces règles restent dans OBS : Sillonette ne les voit pas.
